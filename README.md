## 🚀 About The Project

**RELIA** (Roteiro Empático de Leitura com Inteligência Artificial) is a groundbreaking educational research project funded by **FCT (Fundação para a Ciência e a Tecnologia)**.

We are integrating **Generative AI**, **Reading Mediation strategies**, **Bloom’s Taxonomy**, and **Digital Literacy frameworks** to promote critical thinking, empathy, and literary comprehension in secondary and higher education.

### 🌟 Vision
To transform the public reading ecosystem through a perfect synergy of:
- **Artificial Intelligence** 🤖
- **Data Science** 📊
- **User-Centered Service Design** 🎨

## ✨ Key Features

- **AI-Powered Mediation**: utilizing LLMs to guide students through complex literary texts.
- **Cognitive Scaffolding**: based on Bloom's Taxonomy to ensure deep understanding.
- **Digital Literacy**: empowering users to navigate the digital information age.
- **Empathy Engine**: fostering emotional connection with literature.

## 🛠️ Technology Stack

Built with a modern, high-performance stack designed for the future of web:

- **⚡ Core**: Next.js 16 (App Router)
- **🎨 Styling**: Tailwind CSS 4 & shadcn/ui
- **📘 Language**: TypeScript 5
- **🧩 State**: Zustand & TanStack Query
- **🚀 Animation**: Framer Motion
- **🔐 Auth**: NextAuth.js
- **🗄️ Database**: Prisma ORM

## 📂 Project Structure

```bash
src/
```

## 🚀 Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/rshermans/relia-project-site.git
    ```
2.  **Install dependencies**
    ```bash
    npm install
    # or
    bun install
    ```
3.  **Run the development server**
    ```bash
    npm run dev
    ```
4.  **Open [http://localhost:3000](http://localhost:3000)**
